🧠 SINGLE SOURCE OF TRUTH

All major event content is centralized inside:

src/lib/config.ts

This keeps the UI separated from event data.

                 EVENT DATA
                     │
                     ▼
              ┌──────────────┐
              │ config.ts    │
              └──────┬───────┘
                     │
        ┌────────────┼────────────┐
        ▼            ▼            ▼
      Hero         Tracks       Timeline
        │            │            │
        └────────────┼────────────┘
                     ▼
               UI EXPERIENCE

This makes event updates significantly easier without modifying individual components.

🛡️ PERFORMANCE & RESILIENCE

A visually intense WebGL website should never sacrifice usability.

The project includes several defensive systems.

🧯 WebGL Error Boundary

The 3D track experience has an error boundary.

If WebGL fails:

WebGL
  │
  ├── ✅ Available
  │      ↓
  │   3D Solar System
  │
  └── ❌ Failed
         ↓
    HTML fallback

This prevents a graphics failure from crashing the entire page.

♿ Reduced Motion

The project respects reduced-motion preferences and adapts animations accordingly.

📱 Responsive Experience

The experience adapts across:

Desktop
   ↓
Tablet
   ↓
Mobile

while maintaining the core visual identity.

🧑‍🚀 GET STARTED

1. Clone the repository

git clone <your-repository-url>
cd clashofcoder3.0-hackathon-sample-web

2. Install dependencies

Using npm:

npm install

Or using Bun:

bun install

3. Start the development server

npm run dev

or:

bun run dev

4. Launch Mission Control 🚀

Open the local development URL shown in your terminal.

⸻

🧪 BUILD FOR PRODUCTION

npm run build

Preview the production build:

npm run preview
